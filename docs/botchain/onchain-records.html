Scope — please read first

Selkie has not yet deployed to BOT Chain, and therefore has no BOT Chain on-chain history. This application is a request to deploy natively. The records below are Selkie's existing settlement history on the Canton Network DevNet, provided as evidence of a working on-chain product rather than as BOT Chain activity. We state this explicitly rather than omit it.

1 · How to verify this

Canton is a privacy-preserving ledger: contracts are visible only to their stakeholders, so there is no public block explorer that can display a third party's holdings, and no Dune dashboard is possible. Verification is done by querying the participant node directly with credentials for the party in question. Everything in this document was produced by such a query, executed read-only against the live shared DevNet participant on the date shown.
